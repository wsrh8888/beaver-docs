# 本地开发

## 启动开发环境

```bash
npm run dev
```

启动后会自动打开桌面应用窗口，支持热重载开发。

## 开发说明

### 开发特性

- **热重载**: 修改代码后自动重新编译和刷新应用
- **实时预览**: 界面变化实时反映
- **调试信息**: 控制台输出详细的开发调试信息

### 开发端口

- 默认开发端口: 自动分配
- 如遇端口冲突，请检查控制台错误信息
