# 海狸IM 2.1 更新解读：技术栈与功能模块梳理

> 关键词：开源即时通讯、私有化部署、企业 IM、音视频通话、朋友圈、圈子、工作台、OAuth 授权登录

海狸IM 是一款基于 **MIT 协议开源**、支持私有化部署的即时通讯（IM）平台。根据官方更新公告，2.1 已完成多端联调并推送代码，覆盖桌面端、移动端、管理后台、开放平台、OAuth 授权页与服务端。本文基于官方公告与真实桌面端截图，梳理 2.1 的技术栈与主要功能。

---

## 一、海狸IM 是什么？

- **开源免费**：MIT 协议，可商用、可私有化、可二开；
- **私有化部署**：服务与数据全部跑在你自己的服务器，数据自主可控；
- **多端覆盖**：桌面端（Windows / macOS / Linux）、移动端（Android / iOS）、管理后台，一套账号多端实时同步；
- **开放生态**：独立开放平台（beaver-open）+ 统一 OAuth 授权页（beaver-oauth），支持机器人 / Webhook / 事件订阅；
- **消息可靠**：官方文档提及 TCP + ACK 消息必达、端到端加密传输、消息永久存储、多端实时同步。

一句话总结：海狸IM 是一个**能私有化部署、数据自主可控、不绑定商业厂商**的全平台开源 IM。

---


## 二、技术栈（TECH STACK）

海狸IM 后端采用 **Go + Go-Zero 微服务架构**，按业务拆分为 `user / auth / friend / chat / ws / group / file / emoji / gateway / moment / system / config / feedback / track / update` 等十余个独立服务，每个服务预留独立端口，便于多实例水平扩展。完整技术选型如下：

| 层 | 技术 | 说明 |
|----|------|------|
| 语言 / 框架 | Go 1.24 + Go-Zero 1.7 | 微服务 API / RPC |
| 通信 | gRPC、WebSocket、RocketMQ | 服务间调用与实时消息推送 |
| 实时通信 | WebSocket | 长连接实时推送，消息不延迟 |
| 音视频 | LiveKit | 私聊 / 群聊音视频通话 |
| 存储 | MySQL 8.0、Redis 6.0 | 多库拆分 + 缓存会话 |
| 服务发现 | ETCD 3.5 | 服务注册与发现 |
| 消息队列 | RocketMQ | 异步解耦、消息投递 |
| 基础设施 | Docker | 一键编排部署 |
| 桌面端 | Electron + Vue 3 | 跨平台桌面客户端 |
| 移动端 | Flutter | Android / iOS 跨端 |
| 管理后台 | Vue 3 + Element Plus | 运营管理后台 |
| 开放平台 / OAuth | beaver-open / beaver-oauth | 应用配置、授权登录、Webhook |

> 技术栈均取自 beaver-server 官方 README 与 `go.mod` / `docker-compose.yml`。可私有化部署：一条 `docker-compose up` 即可拉起 MySQL / Redis / ETCD / LiveKit / RocketMQ 全套依赖，开箱即用。

## 四、登录体系：密码、扫码，以及 OAuth 授权码登录

2.1 重构了登录体系：桌面端接入 js-sdk，支持密码登录、扫码登录，以及 OAuth 授权码登录；移动端配合 PC 端与开放平台完成扫码确认；服务端补齐了多端登录的设备登记与管理、扫码登录、OAuth 登录。

![密码登录](https://i-blog.csdnimg.cn/direct/3229c1fc62ee4677af072ce113afe407.png)

![扫码登录](https://i-blog.csdnimg.cn/direct/5f82e082310a4966bc14d3142cd3f185.png)

> 关于授权登录：第三方网站或应用可跳转 beaver-oauth 统一授权页，通过扫码或密码登录完成授权并换取 Token；移动端 App 扫码确认即可完成登录。这一能力由 beaver-oauth 统一授权页与开放平台共同支撑。

## 十一、管理后台与开放平台（后台能力一览）

除了桌面端，海狸IM 2.1 还配套了完整的运营与管理能力（以下为后台能力，本篇以桌面端截图为主，未展示后台界面）：

- **运营工作台**：数据概览、待办收件箱、趋势统计；
- **用户 360**：用户全貌、封禁解封；
- **连接监控**：在线用户汇总、PC / 移动端分布、登录设备详情；
- **消息审计**：消息检索、会话审计、批量处置；
- **内容安全**：举报工单、敏感词库、审核案件；
- **开放生态**：开发者审核、应用审核、Webhook 日志；
- **版本发布**：应用 / 架构 / 版本 / 灰度策略；
- **资源管理**：文件存储、表情包管理。

开放平台（beaver-open）已上线开发者门户、应用配置（凭证 / OAuth 登录 / 权限 Scope）、机器人能力（智能机器人 + Incoming Webhook）、事件订阅（Webhook 回调）与安全设置（IP 白名单、可信域名）。beaver-oauth 提供**统一 OAuth 授权登录页**与**扫码引导页**，与开放平台、PC 端、移动端三方联调打通。
