# 海狸IM 2.1 圈子模块怎么用：从建组到拉人

很多人用了海狸IM 一阵子才发现，「圈子」这个东西不是群聊，也不是朋友圈，它是一个独立模块。这篇就单独把它拆开说清楚。

## 一、圈子不是群聊，也不是朋友圈

先把三个概念区分开：

- **群聊**：以消息流为主，几个人到几百人，消息滚得很快，过了就沉下去。
- **朋友圈**：个人状态广播，所有人都看得到，互动是点赞和评论。
- **圈子**：以**帖子**为主，更像一个小型社区或兴趣组。建圈的人定主题，发帖子是主要动作，互动是围绕帖子展开的。

海狸IM 把这三件事在产品里做成了三个并列模块。桌面端左下角的导航里能找到圈子的入口。

## 二、桌面端的圈子页面长什么样

打开桌面端的圈子窗口，是三栏布局（来自 `beaver-desktop/src/render/windows/circle/page/circle/index.vue`）：

![桌面端圈子主页](https://i-blog.csdnimg.cn/direct/7637fc896c7e438091f06ab18804d76f.png)

从左到右：

1. **左栏**：我加入的所有圈子列表，点左上角的「+」可以建新圈子。
2. **中栏**：选中圈子后，看到的是这个圈子的帖子流。
3. **右栏**：圈子的简介、成员、最近动态。

圈子详情和帖子详情都是弹窗模式（modal），点开覆盖在主界面上，关闭回到三栏视图。这么做的好处是看帖子不用跳页，浏览的连贯性比较强。

## 三、建一个圈子

点左栏的「+」，弹出来的是创建圈子的表单。

![创建圈子弹窗](https://i-blog.csdnimg.cn/direct/2553bc4d5e2849fbbb4d8896c0075917.png)

需要填的东西都很直接：

- 圈子名称（必填）
- 圈子简介（可选）
- 头像（可选）
- 是否公开（公开圈能被搜索到，私密圈只能靠邀请加入）

创建成功后，新圈子会立刻出现在左栏列表里，同时你自己就是圈主。

## 四、发帖子和互动

进入圈子后，点中栏上的「发帖」按钮，进入编辑器。

![圈子发帖](https://i-blog.csdnimg.cn/direct/1920a41ef1e6456ab2cdc711bf450574.png)

帖子支持图文混排，写完发布就出现在帖流里。

帖子详情页支持评论、点赞、收藏：

![圈子帖子详情](https://i-blog.csdnimg.cn/direct/5f69c1d739ff4092bfa416bfe653a6bb.png)

互动逻辑和朋友圈差不多，但只对圈子内的成员可见，不像朋友圈那样对所有好友开放。

## 五、三种拉人方式

圈子建好之后，得有人进来。桌面端圈子提供了三种拉人入口：

第一种是**会话入口**。在聊天会话列表里，如果某个会话被识别为来自某个圈子，点进去会直接看到圈子详情页：

![从会话进入圈子](https://i-blog.csdnimg.cn/direct/9177b9e0d3a4483295b89b5dc16a8268.png)

第二种是**分享**。点圈子详情页上的「分享」按钮：

![圈子分享入口](https://i-blog.csdnimg.cn/direct/a78175117a504b6aaa9b73845f5e0d9d.png)

可以选择「分享给好友」（走普通 IM 消息流程）或「分享名片」：

![圈子分享名片](https://i-blog.csdnimg.cn/direct/8f054b42139f4294859133573d6e4935.png)

名片的好处是带圈子的简介、海报、二维码，受邀方扫一下就能加入。

第三种是**圈子二维码**。每个圈子都有自己的专属二维码，适合线下场景，比如活动现场贴在易拉宝上：

![圈子二维码加圈子](https://i-blog.csdnimg.cn/direct/adb174f0b65d4d7d8749635af3555733.png)

二维码扫出来是个加入页面，对方确认后即加入圈子，不需要先加好友。

## 六、移动端 Flutter 的圈子模块

移动端目前没有专门给圈子做的截图，但代码层面这一块是齐的。`beaver-flutter/lib/features/circle/` 下面有 7 个子模块：

| 子模块 | 作用 |
|--------|------|
| detail | 圈子详情页（成员、简介、设置） |
| feed | 帖子流（看帖、刷新） |
| invite | 邀请页面（生成二维码/分享） |
| join | 通过二维码/邀请码加入圈子 |
| list | 圈子列表（我加入的、推荐的） |
| post | 发帖子（编辑器） |
| setting | 圈子设置（圈主/管理员可见） |

也就是说，数据层和路由是齐的，移动端能不能直接用，取决于你的版本是不是最新打的包。Flutter 端的截图仓库里暂时没收录圈子图，但你可以照着桌面端的流程走，差别只在窗口大小。

## 七、和群聊比，到底什么时候该用圈子

我的经验是这么划：

- **2 个人反复协作** → 私聊
- **3-50 人围绕一个项目快速沟通** → 群聊
- **想沉淀资料、写文档、长期积累** → 圈子
- **通知全公司的人** → 公告群 + 朋友圈

群聊的消息会被新消息冲走，但圈子的帖子是长期可见的，搜索也能搜到。如果你发现团队里很多文档、知识、问答其实更适合沉淀而不是即时聊，那就该建圈子。

## 八、目前的边界

照实说：

- 圈子没有子频道（Discord 那种多频道），结构是单层帖子流。
- 没有看到圈主转让功能（只看到 quit）。
- 移动端的圈子 UI 还没完整收口（代码有但没截图，意味着可能还在调）。
- 圈子搜索目前看代码只能搜自己加入的，公开圈子的全站搜索还没做。

这些后面看作者什么时候补齐。如果你现在就要用，桌面端这一套已经能跑通完整的建圈-发帖-拉人-互动流程。
