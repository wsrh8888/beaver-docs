# 海狸IM 2.1 移动端解读：Flutter 客户端界面与功能

海狸IM 是一个基于 MIT 协议开源、支持私有化部署的即时通讯平台，后端采用 Go + Go-Zero 微服务。它的客户端覆盖桌面端（Electron + Vue 3）、移动端和运营管理后台三套，共用同一套账号与后端。本文聚焦**移动端**——用 Flutter 构建的 Android / iOS 应用，基于真实界面梳理它提供的功能和用法，不评价、不对比，只讲清楚「手机上能做什么、怎么用」。

## 一、移动端是什么

移动端面向的是触屏、碎片化的使用场景，设计上强调打开快、单手可操作、扫码这类手机专属能力。

- **技术选型**：移动端基于 **Flutter** 构建，一套 Dart 代码同时编译出 Android 和 iOS 两个安装包，界面与交互在两端保持一致；对做二次开发的开发者来说，只需维护一套代码。
- **账号互通**：它和桌面端、管理后台共用同一后端与账号体系，消息走 WebSocket 实时推送，所以电脑上发的消息手机能收到，反过来也一样。
- **覆盖场景**：移动端覆盖沟通、社交与轻量办公，是桌面端的延伸入口。

补充一句技术栈背景：海狸IM 后端是 Go + Go-Zero 微服务，实时通信基于 WebSocket，音视频基于 LiveKit；移动端用 Flutter 实现双端一致。后面不堆术语，主要带你看界面和用法。

## 二、登录与账号

任何 IM 的第一步都是登录。移动端支持密码登录，也支持 OAuth 授权码登录 + 移动端扫码确认。

日常用得最多的是**密码登录**，忘记密码也能在手机上直接走**找回密码**流程，不用切回电脑。

另一种情况是 **OAuth 授权码登录 + 移动端扫码确认**：当你在桌面端或网页里点开某个接入了海狸IM 的第三方应用、需要授权时，手机会弹出确认提示，点一下「确认」就完成登录，全程不用反复输账号密码。在私有化部署中，多个内部系统接入海狸IM 做统一授权时，这条链路可以减少重复输密码。

## 三、聊天

**消息列表**按时间排序，未读消息用红点标出，并且和桌面端实时同步——电脑上看过的会话，手机上红点也会消。

## 八、移动端还支持什么

除了上面这条主线，移动端在工程里还实现了**圈子、工作台、OAuth 扫码**等模块，并且和桌面端数据互通。

- **圈子**：带主题的社区板块，可以在手机上刷动态、参与讨论；
- **工作台**：桌面端嵌的第三方应用入口，手机上同样能打开，外出时用工作台处理审批类事务；
- **OAuth 扫码确认**：前面登录里提到的「手机确认即登录」，就是在这里落地的。

这些模块和前面讲的是同一套账号、同一套后端，体验是连贯的，按自己的使用节奏去探索即可。
