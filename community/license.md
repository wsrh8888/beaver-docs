## 二、免费使用范围（保留署名即可）

**口诀：**

- **闭源 + 自用 + 前端保留「关于」署名 = 免费商用**，无需购买付费授权。
- **二次开源（对外公开源码）= 免费，无需付费**，但**必须**保留 `LICENSE`、版权注释，并在前端「关于」中署名（见下）。

### ✅ 允许（免费）

- 个人学习、非商用
- **闭源自用商用**：自己公司业务使用、给自己平台的社群 / 客户使用；二次开发新增代码无需对外开源
- **二次开源**：基于本项目二次开发后，将衍生作品以开源形式公开发布（如 GitHub / Gitee Fork、新开仓库），**不收取任何授权费用**；但必须遵守署名与 `LICENSE` 保留要求（见下节），不得删除海狸 IM 来源标识、不得宣称整体为完全自主原创
- 不限聊天账号、不限终端用户数量（按企业全职员工人数计费的是商业授权档位，不是按 IM 用户数）

### 📝 前端署名界面（强制）

只要基于本项目部署上线、对外可访问（含对内正式业务系统），**必须**提供一个**独立的署名界面**（整页或整窗均可），并**显著展示**署名信息，不得弱化、遮挡、仅藏在源码注释里。

#### 入口与命名（强制什么、不强制什么）

| | 说明 |
| --- | --- |
| **强制** | 有**独立署名界面**；入口显著——与「设置」同级，或在设置内为**一级菜单**（禁止藏在「通用 → 其它 → …」多级深处） |
| **名称不限** | 可不叫「关于」。推荐更直白的名字，例如：**海狸署名**、**开源致谢**、**开源声明**、**关于海狸** 等，只要用户能自然找到即可 |
| **不强制** | 不要求必须做成桌面端那种「再开一个独立应用窗口」；App / H5 / 管理后台用应用内独立页面即可 |

**官方示范：** 海狸桌面端「开源致谢」页——标题写明「本项目使用了开源项目 海狸 IM (Beaver IM)」，并列出**实际用到的全部仓库**（名称 + 可点击地址），而不是只贴一个链接敷衍了事。
